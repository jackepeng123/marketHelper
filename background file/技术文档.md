# 1、项目背景

糕点城目前面临着操作困难、不会决策、灵感缺失等问题。本项目旨在构建一个基于AI Agent的智能门店运营系统，通过整合多渠道数据，结合各种实用工具，利用大模型进行快速分析、深度决策等等，实现从“被动记账”到“主动智能决策”的转型。系统将提供智能对话、营销策略生成、实际场景分析等核心能力，辅助店内快速针对某些商品制定对策或提供新品的推荐。

# 2、技术选型

- LangChain:封装模型接口、进行Prompt调优、搭载文档解析、实现工具调用
- LangGraph:拆分用户意图至多个子Agent，持久化对话历史、接入多模态
- DeepAgent:回答子agent的各个问题，从多个角度进行综合推理
- agent框架
- SSE协议:实时推送、流式输出
- RAG:搭建知识库与向量数据库，收录历史输出，减少模型幻觉
- Redis:流量控制、流式缓存
- phoenix:集成至LangGraph、调用链路追踪、优化Prompt和工具使用
- postgreSQL:存储对话快照、存储历史对话与常见业务数据
